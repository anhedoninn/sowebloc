# SOWE — сайт бренда

Статический сайт: HTML/CSS/JS, без сборки и зависимостей.

## Структура

```
index.html          разметка всего сайта (один файл, все секции)
styles.css           стили и дизайн-токены (цвета, шрифты — в начале файла)
script.js             интерактив: галерея, выбор цвета/размера, корзина, аккордеон, меню
assets/img/          фото + постеры для видео + логотип
assets/video/        два фоновых видео в hero-секции
```

## Как открыть в VS Code

1. Открой папку целиком: `File → Open Folder…` → выбери эту папку.
2. Поставь расширение **Live Server** (автор ritwickdey) — VS Code сам предложит
   его при открытии папки, либо возьми во вкладке Extensions.
3. Правый клик на `index.html` → **Open with Live Server**. Сайт откроется в
   браузере на `localhost` с автообновлением при сохранении файлов.

Без Live Server тоже работает — можно открыть `index.html` прямо в браузере
двойным кликом, просто не будет автообновления при правках.

## Где что менять

- **Цена** — ищи `10.500 сом` в `index.html` (2 места) и `script.js` (1 место,
  в шаблоне корзины).
- **Цвета / шрифты** — переменные `:root` в самом верху `styles.css`.
- **Тексты** — весь текст сайта на русском лежит прямо в `index.html`.
- **Фото/видео** — просто замени файлы в `assets/img/` и `assets/video/` тем
  же именем, либо поменяй пути в `index.html`.

## Важно

Корзина и форма подписки работают только на фронтенде (без сервера) — это
демонстрация интерфейса, для реальных заказов и рассылки нужно будет
подключить бэкенд или сервис оплаты/почты.
